# v0.6.0 — S3 Download Reliability, Dataset Stats Pagination, Permission Fixes

## Summary

Fixes critical S3 download reliability issues where presigned URL imports produced corrupt archives, adds magic-byte archive detection as a fallback for extensionless files, paginates the dataset stats endpoint, introduces a new AI service permission class for job start, seeds the DOWNLOADING upload status, and switches the database engine to PostGIS.

## All Changes

### Bug Fixes

- `fix(uploads)`: Rewrote `copy_from_presigned_url` to use `iter_content()` with a temp file instead of `response.raw`, which failed to decode content-encoding — fixing corrupt ZIP downloads from S3 presigned URLs.
- `fix(uploads)`: `process_archive_task` now detects archive type via magic bytes (ZIP `PK\x03\x04`, GZIP `\x1f\x8b`, RAR `Rar!`) when the file has no extension, preventing "File is not a valid zip archive" errors.
- `fix(uploads)`: `get_datasets_stats` counts only IMAGE file types for `total_files` instead of all upload records, giving accurate image counts per dataset.
- `fix(uploads)`: Renamed `dataset_status` field to `status` in the dataset stats response for frontend consistency.
- `fix(uploads)`: Added DOWNLOADING to the set of "processing" statuses so in-progress downloads are not incorrectly marked as completed.
- `fix(uploads)`: `validate_file_url` now uses `requests.get(stream=True)` instead of `requests.head()` to validate S3 presigned URLs that only support GET.
- `fix(config)`: Changed `DB_ENGINE` to `django.contrib.gis.db.backends.postgis` for PostGIS spatial support.

### Features

- `feat(uploads)`: `UserDatasetsStatsView` now supports pagination with `page` and `page_size` query parameters using `StandardResultsSetPagination`.
- `feat(jobs)`: New `IsAIServiceOrAuthenticated` permission class — allows AI service token or standard user authentication for the start-job endpoint.
- `feat(uploads)`: Added extensive logging throughout S3 download and archive processing: response headers, file sizes, hex signatures, and extraction progress.

### Infrastructure

- `feat(uploads)`: New migration `0008_add_downloading_status` seeds the DOWNLOADING status into the upload status table.
