# v0.10.4 — Raw Band Ortho ZIP Product Types

**Date:** 2026-04-28

Five new product type choices are added to the `Product` model so the AI
gateway can upload per-band orthomosaic ZIP archives and the frontend Products
page can render them with a Download button.

Previously, only vegetation indices and the stacked `calibrated_reflectance`
raster were exposed to the user.  The raw per-band GeoTIFFs (Green, Red, Red
Edge, NIR, Blue) were generated on the AI side but had nowhere to land in the
database because their type strings were not in `PRODUCT_TYPE_CHOICES`; any
upload attempt would have failed at the serializer validation step.

---

## All Changes

### Features

- `feat(products)`: Add five new product type choices to
  `Product.PRODUCT_TYPE_CHOICES` under a new "Raw Band Orthos (ZIP archives)"
  comment block:
  - `band_green` — Green Band Orthomosaic (ZIP)
  - `band_red` — Red Band Orthomosaic (ZIP)
  - `band_red_edge` — Red Edge Band Orthomosaic (ZIP)
  - `band_nir` — NIR Band Orthomosaic (ZIP)
  - `band_blue` — Blue Band Orthomosaic (ZIP)

### Infrastructure

- `ci(products)`: Migration `0005_add_raw_band_product_types` — `AlterField`
  on `Product.type` to include the five new choices.  No schema change (the
  column is `VARCHAR(50)` and the new values fit); the migration updates only
  the choices constraint recognised by Django.
