# v0.1.0 — Dynamic Metadata Extraction & Configurable Extensions

**Release Date:** 2026-03-05

## Summary

Initial versioned release. Adds dynamic handling of metadata files (`.nav`, `.obs`, `.mrk`, `.bin`, etc.) inside uploaded zip archives, configurable file extension lists via environment variables, and presigned URL generation for metadata files sent to the AI service.

## All Changes

### Features
- `feat(uploads)`: Archive extraction now handles metadata files (`.nav`, `.obs`, `.mrk`, `.bin`, `.pos`, `.csv`, `.txt`, `.log`, `.rtcm`, `.ubx`, `.rinex`, `.json`, `.xml`) alongside images.
- `feat(uploads)`: Added `METADATA` file type to `Image.FileType` model choices.
- `feat(uploads)`: Metadata files stored under `{base_path}/metadata/{upload_id}/` with separate tracking.
- `feat(jobs)`: Added `generate_dataset_metadata_urls()` — generates presigned URLs for metadata files and includes them in AI Gateway payload as `parameters.metadata_urls`.
- `feat(settings)`: Added `DATASET_IMAGE_EXTENSIONS` and `DATASET_METADATA_EXTENSIONS` as configurable env var lists with sensible defaults.

### Bug Fixes
- `fix(uploads)`: Metadata files (`.nav`, `.obs`, `.mrk`, `.bin`) are no longer silently skipped during zip extraction.

### Infrastructure
- `docs(versioning)`: Introduced changelog system under `docs/changelogs/` with semantic versioning.

### Breaking Changes
- No breaking changes.
