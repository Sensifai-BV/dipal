# v0.2.0 — Analysis Mode Support

## Summary

Adds the `analysis_mode` parameter to the processing pipeline, allowing users
to choose between **fast** (RGB-only, default) and **full** (RGB + multispectral
analysis with vegetation indices) processing modes. This release includes the
database migration, model changes, serializer updates, and business logic
validation across the entire job domain layer.

---

## All Changes

### Features

- **feat(jobs):** Add `AnalysisMode` TextChoices enum (`FAST`/`FULL`) to
  `processing_stages.py`.
- **feat(jobs):** Add `analysis_mode` CharField to `ProcessingJob` model with
  default `"fast"` and max length 10.
- **feat(jobs):** Add `analysis_mode: str = "fast"` field to `JobEntity`
  dataclass.
- **feat(jobs):** Add `analysis_mode` ChoiceField to
  `ProcessingJobCreateSerializer` with `fast`/`full` choices.
- **feat(jobs):** Add `analysis_mode` read-only field to
  `ProcessingJobListSerializer`.
- **feat(jobs):** Add `analysis_mode` parameter to
  `StartProcessingUseCase.execute()` with validation (rejects invalid values
  with `BusinessRuleValidationException`).
- **feat(jobs):** Include `analysis_mode` in `ProcessingJobRepository.create_job()`.
- **feat(jobs):** Pass `analysis_mode` in Celery task `parameters` dict to
  AI Gateway.

### Infrastructure

- **ci(jobs):** Migration `0005_add_analysis_mode` — adds `analysis_mode`
  column to `jobs_processing_job` table.

### Bug Fixes

No changes.

| Change | Impact | Action Required |
|--------|--------|-----------------|
| New optional field `analysis_mode` on `POST /v1/api/jobs/start-job/` | Accepts `"fast"` (default) or `"full"`. Existing requests without this field default to `fast` — fully backward-compatible. | No action for current behaviour; pass `"full"` to enable multispectral products. |
| New column `analysis_mode` on `ProcessingJob` model | Appears in job list endpoint as a new read-only field. | Run migration `0005_add_analysis_mode` on all environments. |
| `analysis_mode` included in `ProcessingJobListSerializer` response | Additional field in job list JSON. | Frontend may display if desired; backward-compatible. |
