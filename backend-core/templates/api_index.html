🚀 Quick Start

  1. Register: POST to /v1/accounts/register/
  2. Login: POST to /v1/accounts/login/ to get token
  3. Use token: Add header Authorization: Bearer <token>
  4. Make requests: Access protected endpoints

🔓 Authentication Endpoints

No Auth Required
POST /v1/accounts/register/
Register a new user account
{
  "email": "user@example.com",
  "password": "password123",
  "confirm_password": "password123"
}
POST /v1/accounts/login/
Login and receive JWT tokens
{
  "email": "user@example.com",
  "password": "password123"
}
GET /v1/accounts/profile/ Auth Required
Get current user profile information

💻 Example Usage

Using curl:

# Register
curl -X POST http://localhost:8000/v1/accounts/register/ \
  -H "Content-Type: application/json" \
  -d '{"email":"test@test.com","password":"pass123","confirm_password":"pass123"}'

# Login
curl -X POST http://localhost:8000/v1/accounts/login/ \
  -H "Content-Type: application/json" \
  -d '{"email":"test@test.com","password":"pass123"}'

# Use token for authenticated requests
curl -X GET http://localhost:8000/v1/accounts/profile/ \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"

📖 Response Format

All responses follow this structure:

// Success
{
  "data": { ... },
  "error": null,
  "is_success": true
}

// Error
{
  "data": null,
  "error": "Error message",
  "is_success": false
}
