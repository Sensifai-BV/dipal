# v0.9.6 — Request ID Tracing Across All Services

## Summary

Enables end-to-end request tracing using chromatrace's `RequestIdMiddleware` on all four FastAPI services. The `X-Request-ID` header from incoming requests is captured and propagated to inter-service HTTP calls, so all logs across the gateway, calibration, SFM, and orthomosaic services share the same trace ID.

## All Changes

### Features

- `feat(api-gateway)`: Added `FastAPIRequestIdMiddleware` to the gateway's FastAPI app. Reads `X-Request-ID` from incoming requests and sets it in chromatrace's context variable.
- `feat(sfm)`: Added `FastAPIRequestIdMiddleware` to the SFM service's FastAPI app.
- `feat(calibration)`: Added `FastAPIRequestIdMiddleware` to the calibration service's FastAPI app.
- `feat(orthomosaic)`: Added `FastAPIRequestIdMiddleware` to the orthomosaic service's FastAPI app.
- `feat(clients)`: SFM, calibration, and orthomosaic clients now forward `X-Request-ID` from the current trace context on outbound requests.
- `feat(clients)`: Backend callback client and product upload client now forward `X-Request-ID` via httpx event hooks.
