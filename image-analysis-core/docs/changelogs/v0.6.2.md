# v0.6.2 — Health Check & Metrics Endpoints

## Summary

Adds a `/health/` endpoint for load-balancer probes and monitoring, and a
`/metrics/` endpoint (JSON + Prometheus text format) exposing job counts,
processing times, and service uptime. Metrics are recorded automatically at
pipeline completion and failure. Includes 13 new unit tests.

---

## All Changes

### Features

- **feat(gateway):** Add `GET /health/` endpoint returning JSON with service
  status, version, uptime, and Redis dependency check. Returns 200 for
  healthy, 503 for unhealthy. No authentication required.
- **feat(gateway):** Add `GET /metrics/` endpoint returning JSON with
  `total_processed`, `total_failed`, `currently_running`,
  `average_processing_seconds`, and `total_processing_seconds`.
- **feat(gateway):** Add `GET /metrics/prometheus` endpoint returning
  Prometheus text-format counters and gauges for scraping.
- **feat(gateway):** Pipeline completion now calls `record_job_completion()`
  with duration calculated from `job_state.created_at`.
- **feat(gateway):** Pipeline failure now calls `record_job_failure()` to
  increment the failure counter.
