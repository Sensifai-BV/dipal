# v0.10.2 — Healthcheck S3 Timeout

## Summary

Adds a 3-second connection and read timeout to the S3 client used in the `/health/` endpoint, preventing the health check from hanging when S3 is unreachable. The S3 → degraded status behavior was already in place from v0.10.1.

## All Changes

### Bug Fixes

- `fix(health)`: Added `BotoConfig(connect_timeout=3, read_timeout=3, retries={"max_attempts": 0})` to the boto3 S3 client in the health endpoint. Previously, `head_bucket()` could hang for ~60 seconds when S3 was unreachable, causing health checks to time out.

### Files Changed

| File | Changes |
|------|---------|
| `api_gateway/app/api/v1/endpoints/health.py` | Added `botocore.config.Config` import, 3s timeout on S3 client |
