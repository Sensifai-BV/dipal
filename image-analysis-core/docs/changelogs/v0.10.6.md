# v0.10.6 — Raw Band Ortho ZIP Downloads

**Date:** 2026-04-28

After multispectral orthomosaic generation, each per-band GeoTIFF (Green, Red,
Red Edge, NIR, Blue) is now archived into a separate ZIP file and uploaded to
S3 as a discrete product.  Users can download any individual band ortho directly
from the Products page in the UI.

Previously, band orthos existed on the server but were not surfaced for download
— only vegetation indices (NDVI, NDRE, GNDVI) and the stacked
`calibrated_reflectance` product were reachable from the frontend.

---

## All Changes

### Features

- `feat(orthomosaic)`: Add `_zip_band_orthos(ms_products, workspace)` to
  `orthomosaic_endpoint.py`.  For every `{band}_ortho` key in the
  multispectral outputs, creates
  `{workspace}/multispectral/bands/{band}_band.zip` (DEFLATE-compressed)
  containing just that single GeoTIFF.  Returns a mapping of
  `band_{band}_zip → zip_path` that is merged into the main `outputs` dict.
  Called automatically after `run_multispectral_analysis`; a no-op when no MS
  analysis ran.
- `feat(gateway)`: `upload_stage_products` in `jobs.py` now iterates over
  `band_green_zip`, `band_red_zip`, `band_red_edge_zip`, `band_nir_zip`,
  `band_blue_zip` output keys and uploads each as the corresponding product
  type (`band_green`, `band_red`, `band_red_edge`, `band_nir`, `band_blue`).
  Only bands present in `outputs` are uploaded — partial sets (e.g. no Blue
  band) are handled gracefully.

### Tests

- `TestZipBandOrthos` (7 tests) in `test_orthomosaic_endpoint.py`:
  - zip created for each `*_ortho` key; non-ortho keys skipped; missing file
    silently skipped; empty input returns empty; zip placed in correct subdir;
    original filename preserved inside zip; all five bands handled together.
- `TestUploadBandZips` (4 tests) in `test_jobs_endpoint_ext.py`:
  - all five bands uploaded with correct product types; missing file recorded
    as failure; band zips + other products uploaded together; only present
    bands uploaded (no phantom failures for absent bands).
