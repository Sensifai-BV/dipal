# v0.10.5 — Geotagged Calibrated Reflectance TIFFs

**Date:** 2026-04-28

Calibrated reflectance images (per-band `.tif` files output by the radiometric
calibration service) are now written as **WGS84-georeferenced GeoTIFFs** instead
of plain floating-point TIFFs with no spatial reference.

Previously, `_save_reflectance_image` used `cv2.imwrite`, which strips all EXIF
and writes no geotransform.  The output was spatially blind — opening a single
reflectance TIFF in QGIS or any GIS tool showed it floating at 0,0 with no CRS.
Any downstream analytics service consuming the calibrated images could not
determine where on the earth the pixels belonged.

The fix reads GPS lat/lon/alt from the original source image EXIF (via Pillow),
computes an approximate GSD from the flight altitude and a 65° default camera HFOV,
derives the four corners of the image footprint, and writes a proper GeoTIFF via
GDAL with WGS84 (`EPSG:4326`) projection.  The fallback to `cv2.imwrite` is
preserved for cases where GPS is absent or GDAL is not installed.

---

## All Changes

### Bug Fixes

- `fix(calibration)`: Replace `cv2.imwrite` in `_save_reflectance_image` with a
  GDAL-based write that embeds a WGS84 geotransform derived from GPS EXIF of the
  original source image.  Each calibrated reflectance TIFF is now a valid GeoTIFF
  with correct spatial reference and can be opened directly in QGIS or any GIS
  tool at the correct geographic location.

### Features

- `feat(calibration)`: Add `_extract_gps_for_reflectance(source_image_path)` helper
  in `calibration_endpoint.py`.  Reads GPS lat/lon/alt from source image EXIF using
  Pillow's `getexif()` + GPS IFD (tag `0x8825`).  Shares the same EXIF parsing
  approach established in `colmap_service.py` and `ms_orthorectification.py`.
- `feat(calibration)`: Add `_DEFAULT_HFOV_DEG = 65.0` module constant for GSD
  estimation (same default used in the orthomosaic GPS-guided warping).  The
  `source_image_path` parameter on `_save_reflectance_image` is optional — when
  absent (or when GPS / GDAL is unavailable) the function falls back silently to
  `cv2.imwrite`.

### Tests

- Added 8 new unit tests in `test_calibration_endpoint.py` covering:
  - Fallback to `cv2.imwrite` when `source_image_path` is `None`
  - Fallback when `_gdal` is `None` (not installed)
  - Fallback when GPS extraction returns `None`
  - GDAL write path (asserts `SetGeoTransform`, `SetProjection`, `WriteArray`,
    `FlushCache` are called; `cv2.imwrite` is NOT called)
  - Geotransform correctness (UL longitude < GPS longitude, UL latitude > GPS
    latitude, pixel-x positive, pixel-y negative)
  - `_extract_gps_for_reflectance` when Pillow unavailable → `None`
  - `_extract_gps_for_reflectance` when GPS IFD is empty → `None`
  - `_extract_gps_for_reflectance` returns correct `(lat, lon, alt)` tuple

## Product Geotag Status after This Release

| Output file | Geotagged? | CRS |
|---|---|---|
| Original drone images | ✅ GPS EXIF | WGS84 |
| Calibrated reflectance TIFFs (`*_reflectance.tif`) | ✅ GeoTIFF (new) | WGS84 EPSG:4326 |
| Band orthos (`{band}_ortho.tif`) | ✅ GeoTIFF | UTM (derived) |
| DSM (`dsm_filled_cog.tif`) | ✅ GeoTIFF | UTM (derived) |
| RGB orthomosaic (`orthomosaic_rgb.tif`) | ✅ GeoTIFF | UTM (derived) |
| Vegetation indices (NDVI / NDRE / GNDVI) | ✅ GeoTIFF | UTM (derived) |
