# v0.9.0 — Performance: httpx Migration, Parallel I/O, Connection Pooling

## Summary

Major performance release that replaces `aiohttp` with `httpx` across all HTTP
clients, introduces parallel image downloads and product uploads, parallelises
PDAL band pipelines in orthomosaic generation, and unblocks the async event loop
from synchronous SQS and file I/O. These changes collectively eliminate per-request
session overhead, enable connection pooling, and reduce wall-clock time for
image-heavy pipeline stages.

---

## All Changes

### Features

- `feat(clients)`: Replace `aiohttp` with shared `httpx.AsyncClient` instances
  in `SFMClient`, `CalibrationClient`, `OrthomosaicClient`, `BackendClient`,
  and `ProductUploadClient` — one persistent client per service with connection
  pooling and pre-configured base URLs / timeouts.
- `feat(backend-client)`: Add exponential-backoff retry to `_send_callback()`
  with configurable `callback_max_retries` (default 3) and
  `callback_base_delay` (default 1.0 s); delay doubles each attempt.
- `feat(product-upload)`: Pre-fetch all presigned chunk URLs in parallel via
  `_prefetch_chunk_urls()` using `asyncio.gather`, then upload chunks
  concurrently with `asyncio.Semaphore(MAX_PARALLEL_CHUNK_UPLOADS=4)`.
- `feat(product-upload)`: Switch file reads from synchronous `open()` to
  `aiofiles.open()` to avoid blocking the event loop on 500 MB+ chunks.
- `feat(jobs)`: Parallelise product uploads in `upload_stage_products()` — SFM
  pointcloud + mesh upload concurrently via `asyncio.gather`; orthomosaic
  products (up to 13) gathered in a single `asyncio.gather` call.
- `feat(storage)`: Parallelise presigned-URL image downloads in
  `PresignedURLDriver` using `ThreadPoolExecutor(max_workers=8)`.
- `feat(storage)`: Parallelise S3 image downloads in `S3Driver` using
  `ThreadPoolExecutor(max_workers=8)`.
- `feat(orthomosaic)`: Run R / G / B PDAL band pipelines concurrently via
  `ThreadPoolExecutor(max_workers=3)` in `generate_rgb_orthomosaic()`.
- `feat(sqs)`: Wrap synchronous `boto3` `send_message()` calls with
  `asyncio.to_thread()` in `SQSDispatcher` to unblock the event loop.
- `feat(calibration)`: Migrate callback HTTP call in calibration endpoint from
  `aiohttp` to `httpx.AsyncClient`.
