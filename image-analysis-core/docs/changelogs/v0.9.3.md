# v0.9.3 — Orthomosaic Output Path Fix

## Summary

Orthomosaic outputs (DSM, hillshade, orthomosaic RGB, vegetation indices) were being written to the SFM directory instead of the orthomosaic workspace. This release fixes the output path by creating a dedicated orthomosaic workspace and symlinking the SFM `dense/` directory for input access.

## All Changes

### Bug Fixes

- `fix(orthomosaic)`: Orthomosaic outputs were written to the SFM directory because `OrthomosaicService.start()` used the SFM path as workspace. Now creates a separate orthomosaic workspace (`jobs/orthomosaic/<job_id>`) and symlinks the SFM `dense/` directory so pipeline inputs are found while outputs go to the correct location.
- `fix(orthomosaic)`: Resumability check now looks for cached results in the orthomosaic workspace rather than the SFM directory.
- `fix(orthomosaic)`: Multispectral analysis outputs (NDVI, NDRE, GNDVI) now go to the orthomosaic workspace under `multispectral/indices/`.

### Features

- `feat(orthomosaic)`: Result dict now includes `workspace_path` key, giving the API Gateway the actual output directory for uploads.
- `refactor(orthomosaic)`: Extracted `_collect_outputs()` helper for consistent output path collection.

### Infrastructure

- `test(orthomosaic)`: Updated 4 existing endpoint tests for workspace-based output paths and `dense/` directory setup.
- `test(orthomosaic)`: Added `TestCollectOutputs` test class for `_collect_outputs` helper.
- `test(orthomosaic)`: Added `TestSymlinkCreation` test class with 3 tests (symlink created, no symlink when dense missing, workspace_path in result).

## 🔌 Backend Contract Changelog

No changes.
