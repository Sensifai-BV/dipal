# v0.6.1 — Upload Resilience & Orthomosaic DNS Fix

## Summary

Patch release fixing three issues that caused the pipeline to fail after SFM
completion: upload timeouts on large product files, upload failures propagating
as pipeline failures, and incorrect Docker DNS name for the orthomosaic service.

---

## All Changes

### Bug Fixes

- **fix(gateway):** Add configurable timeout (600s), retry (3 attempts with 5s
  delay) to `ProductUploadClient._upload_chunk()`. Previously used `aiohttp`
  default timeout which was insufficient for large pointcloud/mesh uploads.
- **fix(gateway):** Wrap `upload_stage_products()` call in
  `process_callback_async()` with try/except so upload failures no longer
  propagate as pipeline failures. The pipeline now continues to the next stage
  even when non-critical uploads fail.
- **fix(config):** Correct `ORTHOMOSAIC_CLIENT_ADDRESS` from
  `http://orthomosaic:8003` to `http://orthomosaic_generation:8003` to match
  the Docker Compose service name. This resolved DNS resolution failures when
  the API Gateway tried to trigger the orthomosaic stage.
