# v0.10.23 — Inter-band co-registration fixes multispectral index noise/banding

## Summary

The persistent flight-line banding/noise in NDVI/NDRE/GNDVI was traced — after
ruling out radiometric (irradiance/DLS-cosine) and per-pass BRDF causes — to
**inter-band geometric misregistration**: each spectral band was warped onto the
DSM independently using GPS + yaw with a nadir assumption, so the physically
offset M3M lenses landed at slightly different ground positions. Differencing
misregistered bands for a normalised-difference index produces high-frequency
noise that the flight overlap organises into diagonal banding. This release
registers each band to a per-capture reference band (NIR) before warping. On a
12-capture validation subset, RED–NIR mosaic high-frequency correlation rose from
**0.062 to 0.201** (≈3.2×), toward the ~0.30–0.35 single-capture ceiling. The full
diagnostic trail (including the radiometric/BRDF hypotheses that were tested and
ruled out) is in `docs/architecture/adr/0001-multispectral-banding-correction.md`.

## Bug Fixes

### fix(orthomosaic): co-register spectral bands per capture to remove inter-band misregistration

**File:** `services/orthomosaic_generation/app/core/algorithms/ms_orthorectification.py`

**Root cause**

`_warp_reflectance_image` placed each band image on the DSM independently from
GPS + yaw assuming a nadir view. The DJI M3M's four multispectral lenses are
physically offset and body-fixed, so per capture the bands landed at different
ground positions — a consistent ≈ (−12, −6) px offset measured on single captures.
The band mosaics were each internally plausible but mutually misaligned: RED–NIR
high-frequency spatial correlation in the mosaic was **0.006** (co-registered
bands would be ~0.3+ given genuine spectral differences). NDVI = (NIR−Red)/(NIR+Red)
then differenced misaligned images → high-frequency index noise (mosaic residual
NDVI 65 %, NDRE 148 %, GNDVI 59 % of mean). A mosaic-level global registration was
tested and ruled out (the per-capture offset averages to ~0 globally while
remaining as spatially-varying local error), so the fix must be per-capture.

**Fix**

- Added `_phase_correlation_shift` — FFT phase correlation (numpy only) returning
  the integer (dy, dx) that aligns a band to a reference; rejects shifts > 40 px
  as noise.
- Added `_capture_key` — parses the DJI 4-digit capture sequence so all four bands
  of an exposure share a key.
- `orthorectify_bands` builds a `capture_key → reference-band path` map (NIR
  preferred for vegetation contrast; falls back to red_edge/red/green) and passes
  it through `_warp_band_images` to `_warp_reflectance_image`, which shifts each
  band onto its capture's reference band **before** GPS-warping. The reference band
  registers to itself (no-op).

**Impact**

Vegetation-index high-frequency noise/banding is materially reduced. Validation on
a 12-capture subset: RED–NIR mosaic high-freq correlation **0.062 → 0.201** (≈3.2×),
approaching the ~0.30–0.35 intrinsic single-capture ceiling (the residual is
genuine spectral-texture difference between bands, not misregistration). Absolute
radiometric refinements (DLS cosine correction, CRP/ELM) remain future work for
absolute accuracy but are not required for the index-noise fix.
