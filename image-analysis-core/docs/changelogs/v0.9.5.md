# v0.9.5 — Parrot Manufacturer Support, SQS Dispatch Improvements

## Summary

Fixes calibration crash for Parrot (Sequoia) datasets by adding manufacturer fallback, and makes service client URLs optional when using SQS dispatch mode.

## All Changes

### Bug Fixes

- `fix(calibration)`: Added Parrot manufacturer support in `DroneImageProcessorFactory.create_from_manufacturer()`. Parrot datasets (e.g. Sequoia) now use the DJI processor as a fallback instead of raising `ValueError: Unknown manufacturer: 'parrot'`.

### Improvements

- `feat(api-gateway)`: Service client URLs (`CALIBRATION_CLIENT_ADDRESS`, `SFM_CLIENT_ADDRESS`, `ORTHOMOSAIC_CLIENT_ADDRESS`) are now optional. When `DISPATCH_MODE=sqs`, HTTP service clients are not instantiated and these env vars can be omitted.
- `refactor(api-gateway)`: DI container conditionally registers HTTP service clients only when `DISPATCH_MODE != sqs`.
- `docs(.env.example)`: Documented that service client URLs are only required for `DISPATCH_MODE=http`.

### Tests

- `test(calibration)`: Updated `test_create_from_manufacturer_unknown` to use `"unknown_brand"` instead of `"parrot"`. Added `test_create_from_manufacturer_parrot` to verify Parrot maps to `DJI_MAVIC_3M`.
