# v0.5.0 — Band Detection, Calibrator Refactoring & Test Migration

**Release Date:** 2026-03-05

## Summary

Major release introducing the band detection module for automatic multispectral image classification, a full refactoring of the radiometric calibration pipeline using Strategy + Factory patterns, migration of all tests from pytest to stdlib `unittest`, and documentation for adding new calibration pipelines.

## All Changes

### Features
- `feat(band-detection)`: Added `shared/band_detection/` module — automatic classification of drone images by spectral band (RGB, NIR, Red Edge, etc.) with EXIF + filename + wavelength detection methods.
- `feat(band-detection)`: `scan_dataset()` scans a directory and produces a `DatasetBandManifest` with per-band groupings.
- `feat(band-detection)`: `organize_by_band()` copies/moves images into band subfolders and writes a JSON manifest.
- `feat(calibration)`: Refactored calibrators into Strategy pattern — `BaseCalibratorStrategy` interface with `MavicM3MCalibratorStrategy` and `MicaSenseCalibratorStrategy` implementations.
- `feat(calibration)`: Added `CalibratorFactory` for runtime calibrator selection based on drone manufacturer.
- `feat(calibration)`: Calibration endpoint rewritten with production pipeline supporting band-aware processing.
- `feat(api-gateway)`: Callback handler updated to support calibration → SFM → orthomosaic stage progression.
- `feat(sfm)`: SFM service updated with band-aware image handling.

### Bug Fixes
- `fix(band-detection)`: Handle empty wavelength EXIF values gracefully.
- `fix(band-detection)`: Correct `_D` suffix stripping for DJI multispectral filenames.
- `fix(band-detection)`: Improve generic filename pattern matching for non-standard naming.

### Infrastructure
- `refactor(tests)`: Migrated all test files from pytest to `unittest.TestCase` / `unittest.IsolatedAsyncioTestCase`.
- `refactor(settings)`: Full settings audit — consolidated environment variables, added `.env.example`.
- `refactor(storage)`: Added shared storage abstraction in `infrastructure/storage/shared_storage/`.
- `docs(calibration)`: Added `docs/adding_new_calibration_pipeline.md` — guide for adding new drone support.
- `docs(versioning)`: Introduced `pyproject.toml` with semantic versioning and changelog system.
- `ci(settings)`: Restored port vars, renamed bucket `ai_dev_bucket` → `ai_bucket`, removed NDVI from calibration scope.

### Breaking Changes
- No breaking changes.
