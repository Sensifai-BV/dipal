# v1.1.0 — Cancel Job, 3D Viewer Rewrite, Product/Table Fixes

## Summary

Adds job cancellation support, rewrites the 3D PLY viewer with MeshLab-style controls, fixes the TIF viewer for BigTIFF/float data, and resolves multiple product page and table issues.

## All Changes

### Features

- `feat(processing-jobs)`: **Cancel job** button (CircleStop icon, amber) — visible only for `processing`, `queued`, or `pending` jobs. Includes confirmation dialog before cancellation.
- `feat(processing-jobs)`: Retry button now only visible for `failed` jobs (was showing for all statuses).
- `feat(processing-jobs)`: Error message column displays failure reason from backend.
- `feat(three-viewer)`: **MeshLab-style 3D viewer** rewrite:
  - Loading overlay with two phases (download progress + "Building scene…")
  - Info bar: FOV, FPS counter, render mode (POINTS/MESH), model name, vertex/face count, vertex colors indicator
  - Axes gizmo: translucent sphere with X/Y/Z axes, rings for XY/XZ/YZ planes, axis labels
  - Settings panel (gear icon): Grid toggle, Axes Gizmo toggle, Info Bar toggle, Point Size slider, Background presets (Dark/Black/Slate/Light)
  - Auto-detects mesh vs point cloud: uses `THREE.Points` for vertex-only PLY files (fixes garbage triangle rendering)
- `feat(base-table)`: Added `initialPageSize` prop to set default page size per table instance.

### Bug Fixes

- `fix(products)`: `missingProducts` computed now tracks all product types across all pages using a persistent Set, not just the current page.
- `fix(products)`: Default page size set to 20 to show more products at once.
- `fix(tif-viewer)`: Complete rewrite using geotiff library (replaces UTIF). Handles BigTIFF, float32/float64, multi-band, RGB uint8/16, single-band grayscale, and viridis colormap for scientific data.
