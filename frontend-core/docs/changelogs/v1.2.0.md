# v1.2.0 — Request ID Tracing, Retry Cancelled Jobs

## Summary

Adds end-to-end request ID tracing by generating `X-Request-ID` on every API call, enabling correlated logs across frontend, backend, and AI services via chromatrace. Also allows retrying cancelled jobs.

## All Changes

### Features

- `feat(axios)`: Every Axios request now includes an `X-Request-ID` header with an 8-character UUID generated via `crypto.randomUUID()`. This ID propagates through backend and AI services for full request tracing.
- `feat(processing-jobs)`: Retry button now visible for both `failed` and `cancelled` jobs (was `failed` only).

### Files Changed

| File | Changes |
|------|---------|
| `src/core/services/axios.ts` | Added `X-Request-ID` header generation in request interceptor |
| `src/module/processing-job/pages/processing-job/processing-job.vue` | Retry button shows for `failed` and `cancelled` statuses |
