# v1.0.0 — Initial Release: Products, Processing, Dashboard, Configuration, Datasets

## Summary

First production release of the PhotoGear frontend. Implements the complete drone imagery processing workflow: dataset upload (multipart + S3 URL import), processing job management with analysis mode selection, product viewing with fullscreen/3D/NDVI viewers, configuration dashboard with webhook management, and a real-time system health monitor.

## All Changes

### Features

- `feat(products)`: Products page with fullscreen image viewer, stacking fix, band manifest panel, NDVI/NDRE/GNDVI vegetation index viewers, route configuration.
- `feat(products)`: 3D point cloud viewer integration for LAS/LAZ products.
- `feat(processing-jobs)`: Processing jobs page with duration display, stage tracking, pagination support, and error toast notifications on job start failure.
- `feat(processing-jobs)`: Analysis mode selection (`fast` / `full`) in the start-processing dialog with radio button UI.
- `feat(dashboard)`: Dashboard page with summary statistics and quick-access navigation.
- `feat(configuration)`: Configuration page with system health dashboard polling `/health/` endpoint.
- `feat(configuration)`: Webhook management with HTML table layout (URL, Events, Status, Created, Actions columns), create/delete operations.
- `feat(dataset)`: Dataset page using `datasets/stats/` endpoint with image count column, paginated table, proper field mapping (`name`, `status`).
- `feat(dataset)`: S3 URL import form with user-provided dataset name input and real filename extraction from URL.
- `feat(dataset)`: Retry button and confirmation dialog for failed uploads, DOWNLOADING status badge.
- `feat(dataset)`: Dataset download via `window.open()` for cross-origin S3 presigned URLs.
- `feat(layouts)`: Sidebar navigation with all module routes enabled.
- `feat(auth)`: Registration page text and branding updates.

### Core Components

- `feat(core)`: `baseTable` — data tables with pagination, sorting, and named cell slots.
- `feat(core)`: `baseDialog` — modal dialogs with `#body` and `#footer` template slots.
- `feat(core)`: `baseButton` — buttons with variant, size, block, and loading props.
- `feat(core)`: `baseInput` — form inputs with v-model, label, prefix/suffix slots.
- `feat(core)`: `baseBadge` — status badges with color mapping for all job/upload statuses.
- `feat(core)`: `baseIcon` — icon component wrapping lucide-vue-next.
- `feat(core)`: `baseDropdown` — dropdown menu component.
- `feat(core)`: `baseCard` — card layout component.
- `feat(core)`: `baseProgressBar` — progress indicator component.
- `feat(core)`: `pageDescription` — page header with title and description from route meta.

### Infrastructure

- `ci(build)`: Vite 7 build configuration with path aliases and production optimizations.
- `feat(services)`: Axios instance with JWT token interceptor, `await-to-js` error handling pattern.
- `feat(services)`: Toast service for user feedback notifications.
- `feat(router)`: Vue Router setup with `requiresAuth` route guards and role-based access.
- `feat(store)`: Pinia stores with `pinia-plugin-persistedstate` for auth and app state.
- `feat(directives)`: `v-format-date` custom directive for ISO date formatting.
- `docs(copilot)`: Added `.github/instructions/copilot.instructions.md` with full project conventions.

### Bug Fixes

- `fix(dataset)`: Silent `catch { break }` in download function replaced with proper error handling.
- `fix(configuration)`: Health endpoint URL stripped of `v1/` prefix — health is served at Django root, not under API versioning.
- `fix(configuration)`: Amazon section chip styling — fixed oversized margins and padding.
- `fix(dataset)`: Upload from URL no longer hardcodes `"link"` as dataset name — uses user-provided name and extracts real filename.
